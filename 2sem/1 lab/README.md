# Отчет о проделанной работе: Сравнение моделей сегментации облаков точек

## 1. Описание данных

### 1.1 Источник и структура данных
- **Тип данных**: Облака точек, полученные методом имитации наземного лазерного сканирования (LiDAR)
- **Формат**: ASCII .ply файлы
- **Количество объектов**: 503 размеченных облаков точек
- **Разбиение выборки**: 
  - Train: 70% (352 объекта)
  - Validation: 15% (75 объектов)  
  - Test: 15% (76 объектов)

### 1.2 Характеристики облаков точек
Каждая точка содержит:
- Координаты: x, y, z
- Метку класса: `scalar_Label`

- Количество точек: 5,185
- Количество классов: 15 (присутствуют классы 0-8, 10-15, отсутствует класс 9)

## 2. Описание моделей

### 2.1 PointNet
**Архитектура:**
- Классическая архитектура для обработки облаков точек
- Использует симметричную функцию (max pooling) для агрегации глобальных признаков
- Применяет трансформационные сети (T-Net) для выравнивания облака

**Ключевые особенности:**
- Обработка каждой точки независимо через MLP
- Инвариантность к перестановкам точек
- Простая и эффективная архитектура

### 2.2 DGCNN (Dynamic Graph CNN)
**Архитектура:**
- Использует динамические графы для захвата локальной геометрии
- EdgeConv слои для извлечения признаков из соседей
- Построение графа на основе k ближайших соседей в пространстве признаков

**Ключевые особенности:**
- Динамическое обновление графа на каждом слое
- Учет локальной структуры данных
- Лучшая способность к захвату деталей геометрии

### 2.3 PointNet++
**Архитектура:**
- Иерархическая структура с Set Abstraction слоями
- Использование FPS (Farthest Point Sampling) для выбора центроидов
- Feature Propagation для восстановления разрешения

**Ключевые особенности:**
- Многоуровневое представление данных
- Захват как глобального, так и локального контекста
- Устойчивость к неравномерной плотности точек

## 4. Анализ результатов

### 4.1 Общая производительность
1. **PointNet++ показывает наилучшие результаты** по всем основным метрикам:
   - Лучший mIoU (0.9164) - на 8.76% лучше DGCNN и на 10.57% лучше PointNet
   - Лучший F1 Macro (0.9555) - на 5.93% лучше PointNet и на 10.24% лучше DGCNN

2. **Все модели показывают высокую точность** (>97%), что указывает на хорошую способность к общему распознаванию.

### 4.2 Per-class анализ
**Сильные стороны PointNet++:**
- Значительное улучшение на проблемных классах:
  - Класс 1: улучшение с 0.562 (PointNet) до 0.861 (+53%)
  - Класс 2: улучшение с 0.495 до 0.870 (+76%)
  - Класс 8: улучшение с 0.564 до 0.842 (+49%)
  - Класс 9: улучшение с 0.628 до 0.866 (+38%)

**Проблемные классы:**
- DGCNN показывает худшие результаты на классах 1, 2, 8, 9 (mIoU < 0.5)
- PointNet испытывает трудности с классами 1, 2, 8 (mIoU < 0.6)

**Хорошо распознаваемые классы:**
- Классы 10-15: все модели показывают отличные результаты (>0.95 mIoU)
- Класс 0: стабильно высокие результаты у всех моделей

### 4.3 Влияние дисбаланса классов
Модели демонстрируют:
1. **Отличное распознавание мажоритарных классов** (0, 10, 11, 12, 13, 14, 15)
2. **Проблемы с миноритарными классами** (1, 2, 3, 4, 8) - представлены менее 1% точек
3. **PointNet++ наилучшим образом справляется с дисбалансом**, особенно на классах 1 и 2
